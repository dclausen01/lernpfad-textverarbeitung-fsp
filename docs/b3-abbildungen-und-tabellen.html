🎯 Das kannst du nach diesem Modul
  • eine Tabelle einfügen und sachlich formatieren,
  • Abbildungen und Tabellen automatisch beschriften – mit Quelle oder „eigene Darstellung“,
  • im Fließtext auf eine Abbildung oder Tabelle verweisen.

1. Was die Richtlinien sagen

Abbildungen – Bilder, Grafiken, Diagramme, Fotos – werden durchnummeriert und bekommen einen eigenen Titel, damit du im Text darauf verweisen kannst. Stammt eine Abbildung aus einer Quelle, steht der Kurzbeleg dabei und die Quelle im Literaturverzeichnis. Hast du sie selbst erstellt: (eigene Darstellung). Diagramme brauchen eine Legende.

2. Eine Tabelle aus den Zahlen bauen

Am Ende deines Basistexts stehen Zahlen mit Tabulatoren dazwischen. Daraus wird jetzt eine echte Tabelle.

Word / OnlyOffice
  1. Die fünf Zeilen (Medium … Hörspiel) markieren.
  2. Einfügen › Tabelle › Text in Tabelle umwandeln… › Text trennen bei: Tabstopps › OK.
  3. Kopfzeile fett, Tabelle über Tabellenentwurf schlicht gestalten (dünne Linien, keine knalligen Farben).
  4. Die Tabelle an eine passende Stelle schieben – z. B. ans Ende von Kapitel 2.1.
LibreOffice
  1. Die fünf Zeilen (Medium … Hörspiel) markieren.
  2. Tabelle › Umwandeln › Text in Tabelle… › Trenner: Tabulatoren › OK.
  3. Kopfzeile fett, Rahmen schlicht halten.
  4. Die Tabelle an eine passende Stelle schieben – z. B. ans Ende von Kapitel 2.1.

3. Automatisch beschriften

Word / OnlyOffice
  1. Tabelle (oder Bild) anklicken.
  2. Referenzen › Beschriftung einfügen (ältere Versionen/OnlyOffice: Registerkarte Verweise).
  3. Bezeichnung Tabelle (bzw. Abbildung) wählen, hinter die Nummer schreiben: : Mediennutzung in einer Kita (eigene Darstellung).
  4. Position: bei Abbildungen unter dem Element, bei Tabellen üblicherweise darüber – Hauptsache einheitlich.

Gibt es „Abbildung“ nicht in der Liste? Über Neue Bezeichnung… anlegen.

LibreOffice
  1. Tabelle (oder Bild) anklicken.
  2. Einfügen › Beschriftung…
  3. Kategorie Tabelle (bzw. Abbildung), Text dahinter: Mediennutzung in einer Kita (eigene Darstellung), Trenner : .
  4. Position: bei Abbildungen unter dem Element, bei Tabellen üblicherweise darüber – Hauptsache einheitlich.

4. Im Text darauf verweisen

Eine Abbildung, auf die der Text nicht eingeht, ist Dekoration. Verweise im Fließtext darauf, z. B.: „Wie Tabelle 1 zeigt, schauen neun von 24 Kindern täglich Videos.“ Am elegantesten als Querverweis – dann stimmt die Nummer auch nach Umbauten: Referenzen › Querverweis › Verweistyp „Tabelle“ › Verweisen auf „Nur Kategorie und Nummer“.Einfügen › Querverweis… › Typ „Tabelle“ › Format „Kategorie und Nummer“.

Tabelle und Diagramm

20 min
  1. Wandle die Zahlen in eine Tabelle um und beschrifte sie automatisch (eigene Darstellung).
  2. Verweise im Text darauf.
  3. Erstelle aus der Tabelle ein Diagramm (Einfügen › DiagrammEinfügen › Diagramm…) mit Legende und beschrifte es als Abbildung.
  4. Lösch die Zeile „Zahlen für eine Tabelle:“ und den Satz zur Erhebung, wenn du sie verarbeitet hast – oder mach daraus einen ganzen Satz im Text.

Plus

Ein Abbildungsverzeichnis

10 min

Bei vielen Abbildungen empfehlen die Richtlinien ein Abbildungsverzeichnis – es steht direkt hinter dem Inhaltsverzeichnis. Füg eins ein: Referenzen › Abbildungsverzeichnis einfügenEinfügen › Verzeichnis › Verzeichnis… › Typ „Abbildungsverzeichnis“. Was passiert, wenn du eine Beschriftung von Hand getippt hättest?

Lösung

Eine von Hand getippte Beschriftung fehlt im Verzeichnis – das Programm erkennt nur automatische Beschriftungen.

Warum lässt du Beschriftungen vom Programm einfügen, statt „Abbildung 1“ zu tippen?

  1. Weil es schneller aussieht
  2. Weil die Nummern beim Umstellen automatisch mitlaufen und ein Abbildungsverzeichnis möglich wird
  3. Weil getippte Beschriftungen nicht gedruckt werden

Was verlangen die Richtlinien zusätzlich bei Diagrammen?

  1. Eine Legende
  2. Eine farbige Gestaltung
  3. Eine eigene Seite
